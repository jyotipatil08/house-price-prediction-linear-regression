# Housing Price Prediction using Linear Regression

A machine learning-based web application that predicts housing and land prices using Linear Regression. The system allows users to estimate property prices based on different input parameters such as location, size, and property type. Developed using Python, Django, and MySQL. 

## 🚀 Features

### Admin Module

* Admin login authentication
* Add house training data
* Add land training data
* Manage locations
* View registered users

### User Module

* User registration and login
* Predict house prices
* Predict land prices
* View property locations
* Submit feedback
* Change password

## 📌 Project Objective

The main objective of this project is to provide accurate property price predictions using Linear Regression based on historical and training datasets. This helps buyers, sellers, and investors make informed real-estate decisions. 

## 📊 Machine Learning Algorithm

### Linear Regression

Linear Regression is used to predict property prices based on independent variables such as:

* Area size
* Number of rooms
* Location
* Accessibility
* Nearby facilities

The algorithm helps generate reliable predictions using training data.

## ⚙️ Installation Steps

1. Clone the repository:

```bash
git clone https://github.com/jyotipatil08/house-price-prediction-linear-regression.git
```

2. Navigate to the project directory:

```bash
cd house-price-prediction-linear-regression
```

3. Install required dependencies:

```bash
pip install -r requirements.txt
```

4. Configure MySQL database.

5. Run database migrations:

```bash
python manage.py migrate
```

6. Start the Django development server:

```bash
python manage.py runserver
```

7. Open in browser:

```bash
http://127.0.0.1:8000/
```
